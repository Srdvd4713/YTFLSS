# Local Deep Research
**GitHub:** https://github.com/LearningCircuit/local-deep-research
**Stage:** Pre-production Topic Research

## What It Does
Turns any topic into a sourced research report using web searches, your local documents, and local or cloud AI.

## Setup (Quick)
1. Clone: `git clone https://github.com/LearningCircuit/local-deep-research`
2. Install deps: `pip install -r requirements.txt`
3. Configure: local model (Ollama) or cloud API key
4. Run: `python main.py --topic "Your Documentary Topic"`

## Prompt Starter
> "Research the full history and controversy of [TOPIC]. Include key events, major figures, turning points, conflicting accounts, and sourced facts. Format as a documentary research brief."

## Tips
- Run on evergreen topics first (history, crime, science)
- Save output reports to this folder for reuse
- Cross-reference with Social Media Research Skills for viral angles
