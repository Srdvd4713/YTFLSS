# Social Media Research Skills
**GitHub:** https://github.com/ScrapeCreators
**Stage:** Competitor Analysis + Hook Mining

## What It Does
Use Claude Code or Codex to:
- Scrape and analyze viral posts
- Break down competitor YouTube channels
- Mine comment sections for audience questions/pain points
- Extract hooks from video transcripts

## Use Cases for Documentary Channels
- Find the top 10 performing videos in your niche
- Extract the exact hook phrases driving clicks
- Identify comment-based story ideas ("what happened to X?")

## Workflow
1. Input: competitor channel URL or niche keyword
2. Tool scrapes top videos + comments
3. Output: hook list, topic gaps, audience sentiment report

## Prompt Example
> "Analyze the top 20 videos on [CHANNEL]. List: hook phrases used in titles, emotional triggers in thumbnails, top comment questions, and content gaps I can fill."
