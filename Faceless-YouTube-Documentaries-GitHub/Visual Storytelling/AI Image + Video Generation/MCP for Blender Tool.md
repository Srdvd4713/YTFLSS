# MCP for Blender (32K ?)
**GitHub:** https://github.com/ahujasid/blender-mcp
**Stage:** LLM-Driven 3D Scene Modeling

## What It Does
Connect Blender to any LLM via MCP protocol:
- Prompt-driven 3D modeling
- Scene composition from text
- Lighting and camera setup
- Animation control

## Setup
1. Install Blender (free: blender.org)
2. Install blender-mcp plugin
3. Connect to Claude / GPT-4 / Gemini via API
4. Start prompting in natural language

## Documentary Scene Prompt Library

### Crime / Investigation
> "Interior of a 1970s detective office. Dim overhead light, filing cabinets, papers on desk, venetian blind shadows on wall. Photorealistic render."

### History
> "Roman forum at sunset, 100 BC. Golden hour light, marble columns, crowd of citizens in togas. Cinematic camera angle."

### Science / Space
> "Deep space nebula with a lone spacecraft approaching a wormhole. Volumetric light, dark background, blue-purple tones."

### Conspiracy / Thriller
> "Dark warehouse interior. Single hanging bulb. Crates stacked. Fog near the floor. Security camera in corner. Surveillance aesthetic."
