# img2threejs (19K ?)
**GitHub:** https://github.com/img2threejs/img2threejs
**Stage:** Image ? Animation-Ready Three.js Object

## What It Does
Give it any reference image ? outputs fully functional Three.js code:
- Code-only (no video model, no GPU render)
- Animation-ready from day one
- Runs in any browser

## Use for Documentary Channel
- Convert key documentary visuals into animated web components
- Build interactive channel website elements
- Create animated Patreon or membership page assets
- Generate thumbnail elements with depth/parallax

## Workflow
1. Select a key image from your documentary (a document, a location, an object)
2. Feed to img2threejs
3. Get Three.js code back
4. Add: rotation, pulse, orbit, or scroll-triggered animation
5. Export as MP4 clip or embed live

## Animation Ideas
- Rotating classified document
- Globe with location pin pulsing
- Newspaper front page with scanline animation
- Timeline slider with 3D depth
