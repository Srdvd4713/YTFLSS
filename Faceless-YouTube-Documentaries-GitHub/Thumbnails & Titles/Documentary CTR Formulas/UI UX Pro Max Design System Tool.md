# UI UX Pro Max (139K ?)
**GitHub:** https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
**Stage:** Full Design System Generation from Brief

## What It Does
Input a project brief ? get a complete design system:
- Color palette (primary, secondary, accent, neutrals)
- Typography scale (display, heading, body, caption)
- Component patterns (cards, badges, overlays)
- Layout grid system

## Channel Brief Template
Paste this into the tool to generate your doc channel brand system:

> "Documentary YouTube channel. Niche: [crime/history/conspiracy/science].
> Tone: authoritative, cinematic, investigative.
> Audience: curious adults 25–45.
> Mood: dark, high-contrast, editorial.
> Avoid: bright colors, playful fonts, rounded corners.
> Preferred style: HBO documentary meets NYT visual design."

## Output ? Use In
- HyperFrames /figma skill (auto-brand all video assets)
- Penpot (build templates from generated tokens)
- diagram-design (pass colors/fonts for branded diagrams)
- FLUX.2 thumbnails (use generated palette in prompts)
