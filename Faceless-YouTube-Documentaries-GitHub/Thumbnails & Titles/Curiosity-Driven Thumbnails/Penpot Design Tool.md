# Penpot (62K ?)
**GitHub:** https://github.com/penpot/penpot
**Stage:** Open-Source Figma Alternative + MCP Server

## What It Does
Full professional design tool with:
- Vector editing (like Figma/Adobe XD)
- Component system
- Team collaboration
- MCP server so AI agents can read your design files

## Why It Matters for Your Channel
- Free and open-source — no monthly subscription
- MCP integration means agents can auto-pull your brand from design files
- Build thumbnail templates once ? reuse every episode

## Thumbnail Template System
Build these core templates in Penpot:

| Template | Purpose |
|----------|---------|
| Face + Text Overlay | Emotional reaction thumbnails |
| Split Reveal | Before/after or comparison |
| Dark + Single Subject | Cinematic/crime style |
| Text Dominant | Quote or shocking stat |
| Archive Style | Historical documentary look |

## MCP Integration
1. Self-host Penpot (Docker: ~5 min setup)
2. Enable MCP server plugin
3. Agent reads: colors, fonts, component sizes
4. Feed tokens ? HyperFrames, diagram-design, Remotion

## Docker Quick Start
```bash
git clone https://github.com/penpot/penpot
cd penpot
docker-compose up -d
# Access at http://localhost:9001
```

## Notes
- Self-hosted = full data ownership, no cloud fees
- Your design files become the source of truth for all branded assets
