# FLUX.2 (Black Forest Labs)
**GitHub:** https://github.com/black-forest-labs/flux
**Stage:** Thumbnail + Visual Asset Generation
**License:** Apache 2.0 (Klein 4B) — commercial use OK

## What It Does
State-of-the-art image generation and editing for:
- Documentary thumbnails
- Scene illustrations
- Social media visuals
- Marketing assets

## Thumbnail Prompt Formula
> "[Emotion] face of [Subject], dramatic lighting, cinematic, dark background, high contrast, photorealistic, 16:9 thumbnail style"

## Example Prompts
- "Shocked man staring at a burning building, cinematic dramatic lighting, documentary thumbnail style"
- "Ancient ruins at golden hour, mysterious fog, aerial view, hyper-realistic"
- "Close-up of classified documents with red CLASSIFIED stamp, dramatic shadows"

## Setup
1. Clone repo + install dependencies
2. Download Klein 4B weights (Apache licensed)
3. Run locally or via ComfyUI interface

## Notes
- Klein 4B runs on consumer GPUs (8GB VRAM+)
- Generate 5–10 thumbnail variants per video, A/B test
- Store winning prompt templates in this folder
