## Rules
- **≤ 60 characters** where possible so it isn't cut off on mobile; the hook words go first.
- Title and thumbnail text must **not repeat** each other. Thumbnail = command ("DON'T ANSWER."), title = situation.
- One CAPS word maximum (the command).
- Include the **Part number** at the end for serials: "… (Part 2)" or the day "(Day 3)".
- Never spoil the twist in a title before Part 5 is out.
- Avoid words that hurt advertiser suitability in titles (kill, dead, blood). Imply instead ("Won't Wake Up").
