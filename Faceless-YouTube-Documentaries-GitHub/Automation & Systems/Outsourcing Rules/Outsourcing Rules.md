# Outsourcing Rules
*The pipeline is mostly automated and local. Outsource only the steps where a human beats the machine, and keep creative control of the story in-house.*

## What to outsource vs keep
| Task | Outsource? | Why |
|---|---|---|
| Series concept, rules, twist, clue table | ❌ Keep | The channel's core IP and quality bar |
| Fact-check sign-off | ❌ Keep (can get a second check) | Safety responsibility |
| Native-speaker review of ES/PT translations | ✅ | Machine translation misses tone and idioms |
| Human listen-through of the final mix | ✅ (or a friend) | Fresh ears catch level problems |
| Community moderation | ✅ later | Time-consuming, low skill once rules are clear |
| Thumbnail concept testing | ⚠️ Maybe | Only with the brand formula as a brief |
| Custom music | ❌ not needed | ACE-Step covers it |
| Voice actor | ⚠️ Later test | Only if TTS starts hurting retention |

## Briefing template
```
TASK: [one line]
CONTEXT: Channel = animated survival series with a real-science twist. Brand rules: CHANNEL BIBLE.md (attach).
INPUT: [files]
OUTPUT: [exact files + format + naming]
QUALITY BAR: [checklist]
DEADLINE: [date, time zone]
PAYMENT: [fixed fee], paid on approval
DO NOT: share or post any file; spoil the twist; use AI tools on [X] unless agreed
```

## Translation review checklist (for the reviewer)
- [ ] Meaning and deadpan tone preserved (short sentences)
- [ ] Rule cards are short and imperative in the target language
- [ ] Line length close to the English (timing)
- [ ] Safety lines exactly correct (generator outside 20+ ft / ~6 m, call the local emergency number)
- [ ] Names, units (ft → m) and emergency number localised

## Hiring
- Platforms: Upwork, Fiverr, or a trusted friend/community member.
- Start with a **paid test** of one Part. Keep the 2 best reviewers per language.
- Pay per Part, fixed. Track in the Multi-Channel Revenue Plan costs column.

## Security
- Share only the files needed (not the whole repo or the YouTube account).
- Never give channel owner access. Use Studio "Channel permissions" with the lowest role needed (e.g. Editor limited or Viewer).
- Unreleased Parts: share as unlisted links or files with a short NDA line in the brief.
