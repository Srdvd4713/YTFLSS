# Short Video Factory
**GitHub:** https://github.com/YILS-LIN/short-video-factory
**Stage:** Short-Form Batch Video Production

## What It Does
Create batches of short videos (Shorts / Reels / TikTok) from:
- Text prompts
- Your existing footage
With: AI scripts, voiceover, auto-editing, and subtitles.

## Use for Faceless Documentary Channels
- Repurpose each full documentary into 5–10 Shorts automatically
- Drive top-of-funnel traffic back to main channel
- Batch-produce weekly Shorts without manual editing

## Workflow
1. Input: documentary topic OR existing video file
2. Set format: vertical 9:16, 30–60 seconds
3. Tool generates: script ? voiceover ? edits ? subtitles
4. Export batch ? upload to Shorts/Reels/TikTok

## Content Ideas from a Single Documentary
- Hook clip (first 60 seconds, vertical)
- Key fact reveal clip
- "What really happened" teaser clip
- Shocking statistic clip
- Call-to-action clip ("Watch the full story")

## Notes
- Build this into your Content Pipeline SOP
- Target: 3 Shorts per full documentary upload
