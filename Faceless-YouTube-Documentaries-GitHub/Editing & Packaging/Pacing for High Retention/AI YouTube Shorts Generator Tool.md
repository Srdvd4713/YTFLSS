# AI YouTube Shorts Generator
**GitHub:** https://github.com/Anil-matcha/AI-Youtube-Shorts-Generator
**Stage:** Long Video ? Shorts Conversion

## What It Does
Convert existing long YouTube videos into vertical Shorts:
- AI selects the best highlight moments
- Auto-transcribes for subtitles
- Automatically crops to vertical (9:16)

## Workflow
1. Input: YouTube video URL
2. AI identifies: top 3–5 highlight moments
3. Auto-crops and exports vertical clips
4. Subtitles added automatically

## Use for Documentary Growth
- Every full documentary upload ? run through this tool
- Get 3–5 Shorts without any manual editing
- Use transcript output for:
  - YouTube chapter markers
  - SEO description copy
  - Social media captions

## Notes
- Pair with Analytics to track which Shorts drive full-doc watch time
- Best clips: reveals, shocking facts, emotional moments
