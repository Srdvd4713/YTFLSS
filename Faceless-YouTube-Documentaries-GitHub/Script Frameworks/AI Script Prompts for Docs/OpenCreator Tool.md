# OpenCreator
**GitHub:** https://github.com/krillinai/OpenCreator
**Stage:** Full Script + Production Pipeline

## What It Does
A creator workspace powered by Codex/LLM that handles:
- Script writing
- Image generation
- Voiceover creation
- Video translation
- Content editing

## Use in Documentary Workflow
- Feed your research brief ? get a full structured script
- Auto-generate scene image prompts alongside the script
- Export to voiceover stage (Kokoro or ElevenLabs)

## Script Prompt Template
> "Write a 10-minute faceless documentary script about [TOPIC]. Use a curiosity-gap hook in the first 30 seconds, build tension through [KEY CONFLICT], include 3 emotional peaks, and end with a satisfying revelation. Tone: authoritative but accessible."

## Notes
- Requires Codex API or compatible LLM
- Pair with your Hook Structures and Narrative Arc folders
