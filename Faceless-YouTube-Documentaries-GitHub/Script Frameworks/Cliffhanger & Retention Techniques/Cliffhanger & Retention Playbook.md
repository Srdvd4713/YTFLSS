# Cliffhanger & Retention Playbook
*How to hold viewers through each 3–8 min Part and pull them into the next one. Pairs with `Hook Structures (Curiosity Gaps)/` and `Tension & Payoff Timing/`.*

## Retention devices (use at least 4 per Part)
| Device | How it works here | Where |
|---|---|---|
| **HUD stat change** | FUEL drops, HEADACHE rises, TALL ONES SEEN ticks up. A visible number change resets attention. | every 40–60 s |
| **Rule card flip** | A 3D rule card with an alarm-red number. A rule is a promise of a test. | first appearance + when tested |
| **Micro-question** | Small open loop closed within 60 s ("Biscuit didn't eat again.") | every 45–60 s |
| **Clue plant** | A fair, unhighlighted clue. Clue hunters rewatch. | 2–6 per Part in P1–P2 |
| **Sound from outside** | knock / name call / hum change. Forces the eyes back on screen. | mid-Part and end |
| **Pattern break** | Hard cut to black + silence for 1–2 s before a reveal | max 2 per Part |
| **Direct question** | Narrator asks himself something the viewer can answer | once per Part |

## Cliffhanger types (end of each Part)
1. **The voice:** someone the viewer trusts speaks from the wrong side of the door. (P4: Grandpa's voice)
2. **The broken rule:** a character breaks a rule and something changes. (P4: June opens the window)
3. **The impossible detail:** "They know our names." (P1)
4. **The reversal card:** the HUD rewrites itself. (P5)
5. **The sequel sting:** new place, same first rule. (P6 → S02)

Rule: end within **3 seconds** of the cliffhanger. Then the end card with the binary question. No outro talk.

## End screen
- Last 15–20 s: end card (binary question) + YouTube end screen element "next Part" (best-for-viewer playlist link for the series).
- VO line before the card: "Part [N+1]. [Title]." Nothing else.

## Where viewers drop off (and fixes)
| Retention graph shape | Likely cause | Fix |
|---|---|---|
| Steep drop 0–30 s | Hook doesn't match title/thumbnail | Rewrite line 1 to echo the thumbnail text |
| Slow slide in the middle | No HUD/rule/sound change for > 60 s | Insert a micro-question or HUD tick |
| Cliff at a specific second | Recap too long, or a static shot > 6 s | Trim; add motion (snow, camera push) |
| Bump up at a moment | Rewatched moment (clue, scare) | Make that moment the Short and the next thumbnail |
| Drop before the end card | Viewers sense the ending | Move the cliffhanger later; card right after it |

## Series-level retention
- Every Part title includes the Part number in the description and pinned comment; playlist order = Parts 1–6.
- Part 7 "Did you catch all 12 clues?" exists to send viewers **back** into Parts 1–2 (session time).
- Pin a comment with the end-card question on upload. Reply to the first 20 comments within the first hour.

## Review step (after 48 h live)
Open Studio → Analytics → Engagement → audience retention. Write down in `EPISODE TRACKER.md`: 30-second retention %, average view %, top spike second, biggest drop second. Apply the table above to the next Part's script.
